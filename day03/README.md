# День 3 — Разные способы рассуждения

Одна аналитическая задача (senior vs два junior), решённая **четырьмя** способами
через API, чтобы сравнить, как меняется ответ от *формы* промпта.

| # | Способ | Техника | Что проверяем |
|---|--------|---------|----------------|
| 1 | Прямой ответ | — | базовая линия, модель «не думает» |
| 2 | «Решай пошагово» | Chain-of-Thought | включаем рассуждение одной фразой |
| 3 | Модель сама пишет промпт | meta-prompting | модель формулирует себе ТЗ |
| 4 | Группа экспертов | multi-persona | аналитик → инженер → критик → итог |

## Ключевое решение
Берём **обычную instruct-модель** (`gemma`), а не reasoning. Reasoning-модель
думает сама всегда → способы 1 и 2 слились бы. Чтобы это увидеть наглядно —
запусти с `--reasoning`.

## Запуск
```bash
pip install -r requirements.txt
cp ../day02/.env .env       # переносим ключ из Дня 2 (или cp .env.example .env и впиши)

# Вариант А — консоль:
python task3.py             # основной прогон на instruct-модели
python task3.py --reasoning # демо: на reasoning-модели способы 1 и 2 схлопнутся

# Вариант Б — GUI (нагляднее, 4 ответа рядом):
python app.py               # затем открой http://127.0.0.1:7860
```

В GUI есть переключатель модели (instruct / reasoning) — щёлкни `reasoning`,
чтобы увидеть, как способы 1 и 2 становятся почти одинаковыми.
