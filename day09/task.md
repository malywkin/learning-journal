# День 9 — Управление контекстом: сжатие истории

## Задание
Реализовать механизм управления контекстом:
- хранить последние **N сообщений** «как есть»;
- остальное заменять **summary** (например, каждые 10 сообщений);
- хранить summary **отдельно** и подставлять его в запрос **вместо полной истории**.

Сравнить:
- качество ответов **без** сжатия;
- качество ответов **со** сжатием;
- расход токенов **до/после**.

**Результат:** агент, который работает с компрессией истории и экономит токены.
**Формат:** видео + код.

## Решение (на наследии Дней 6–8)
- **`compress.py`** — сердце дня. Две стратегии контекста с одной ручкой
  `build(system_prompt, history)`:
  - `NoCompression` — РОЛЬ + вся история (это «до»);
  - `RollingSummary` — РОЛЬ + **копилка** (накопительный summary) + **окно**
    (последние `keep_last` реплик дословно). Рычаги: `keep_last` (размер окна) и
    `trigger` (порог сворачивания). `maybe_compress()` сворачивает всё, кроме окна,
    в копилку, когда несвёрнутых сообщений накопилось ≥ `trigger`.
  - Два guardrail: `DEFAULT_GUARDRAIL` (велит хранить факты, запрещает выдумывать) и
    `NAIVE_GUARDRAIL` («кратко перескажи» — для демо «когда summary вредит»).
- **`agent.py`** — агент Дня 8 + поле `context` (стратегия) + `make_summarizer()`
  (отдельный вызов LLM, температура 0, составляет копилку по guardrail) + учёт токенов
  суммаризации в ledger (сжатие не бесплатно — считаем честно).
- **`demos.py`** — `run_compare()`: один диалог через три режима (plain / smart / naive);
  сажаем ранний факт, выталкиваем за окно, спрашиваем про него → кто вспомнил + токены.
- **`task9.py`** — CLI (чат + `/compress on|off`, `/summary`, `/compare`).
- **`app.py` + `index.html`** — веб-демо (FastAPI, стиль Apple/Butterick, ноль
  зависимостей): чат с тумблером сжатия, «капот» (роль/копилка/окно + пила входа),
  вкладка «Сравнение без/со сжатия».
- `tokens.py`, `memory.py` — без изменений с Дней 7–8.

## Что показал живой прогон (gpt-oss-20b, OpenRouter)
- **Качество:** без сжатия — помнит факт (но дорого); со сжатием+guardrail — помнит
  дёшево; наивное сжатие — те же токены, но факт **потерян и выдуман** (конфабуляция).
- **Токены:** вход финального хода ~580 (без сжатия) против ~326 (со сжатием); кривая
  входа из «лавины» превращается в «пилу» у потолка.
- **Грабли вживую:** на слабой модели инструкция «обязательно сохрани имена/числа» при
  бедном контенте провоцирует ВЫДУМЫВАНИЕ → лечится явным запретом придумывать +
  температурой 0 + коротким потолком сводки.

## Запуск

```bash
python -m venv .venv && ./.venv/bin/pip install -r requirements.txt
./.venv/bin/python task9.py        # CLI (сжатие включено)
./.venv/bin/python app.py          # веб → http://127.0.0.1:8000
```
Ключ `OPENROUTER_API_KEY` — в `.env` (в git не идёт).
