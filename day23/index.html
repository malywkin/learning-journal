Было голый поиск (День 22)

top-K прямо из поиска, по близости к теме. Мусор проходит.

Стало реранк + порог

поиск дал 20 → реранкер оценил каждый → порог отрезал → осталось лучшее.
cos — близость из поиска (День 21): «на ту же ли тему». score — оценка реранкера (День 23): «отвечает ли на вопрос». Кусок с высоким cos, но низким score — это и есть «по теме, но мимо». Режем по score.
