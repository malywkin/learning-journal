# Правила проекта (инварианты)

Ассистент проверяет файлы `sample_project/` на соответствие этим правилам.
Каждое правило проверяемо по коду.

1. **Секреты не в коде.** Ключи/токены/пароли хранятся в `.env`, а не хардкодятся
   в исходниках (`API_KEY = "..."`, `token = "..."` и т.п. — нарушение).
2. **Docstring у публичных функций.** Каждая функция верхнего уровня (не с `_`)
   должна иметь docstring в первой строке тела.
3. **Документация синхронна с кодом.** Сигнатуры в `docs/api.md` должны совпадать
   с фактическими сигнатурами функций в `notes_api.py`.
