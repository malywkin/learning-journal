# API сервиса заметок

Публичные функции модуля `notes_api`.

## `save_note(text)`

Сохраняет заметку с указанным текстом. Возвращает запись с полем `id`.

> Документация отстала от кода: в коде у `save_note` уже есть второй параметр
> `tags`, но здесь он не описан. Сценарий 2 должен это поймать и предложить
> обновление.

## `get_note(note_id)`

Возвращает заметку по её идентификатору или `None`.

## `delete_note(note_id)`

Удаляет заметку по идентификатору.
