# Источники корпуса — родительский дайджест (День 35)

Корпус собран из **официальных** доказательных гайдлайнов. Тексты вшиты дословно; лицензия
каждого источника проверена живьём (роем субагентов, 2026-07-19). В публичный репозиторий
корпус попадает легально: NHS — Open Government Licence (разрешает копирование/адаптацию),
CDC — public domain США. Приватные данные (даты ребёнка) в корпус НЕ входят — они в `.env`.

**Почему именно эти.** Разведка Дня 35 показала: официального ПОнедельного гайда для
младенца ни у кого нет (CDC/AAP/WHO/NHS дают младенца по месяцам и по датам визитов), а
понедельно официально существует только беременность (NHS week-by-week). Поэтому корпус —
NHS (беременность недельно + младенец по этапам) и CDC (вехи по возрастам визитов).

**Чего в корпусе НЕТ намеренно** (дискредитировано, из брифа): «скачки развития по неделям»
(The Wonder Weeks — псевдонаука), «окна бодрствования» и «регресс сна по календарю» (нет в
доказательной медицине), старый совет откладывать аллергены и рисовую кашу как первый прикорм
(развёрнуты консенсусом). AAP/HealthyChildren и ACOG в корпус не вшиты — их лицензия запрещает
републикацию, на них можно только ссылаться.
