# День 35. Реальная задача

Придумать реальную задачу, которую действительно хочется автоматизировать, и сделать
приложение/сервис, который:

- использует AI;
- работает в реальном окружении;
- может быть не полностью рабочим (ключи / доступы).

При сдаче указать, какую задачу решаешь и как в процессе участвует AI.

---

## Что решаю

Родительский дайджест: раз в неделю сам, без ручного запуска, готовит короткую выжимку
«что сейчас важно по возрасту ребёнка» — развитие, на что обратить внимание, кормление,
сон — строго из доказательных гайдлайнов (NHS / CDC), со ссылками, без страшилок и без
выдуманных чисел. Пока ребёнок не родился, работает в режиме «неделя беременности»; после
рождения сам переключается на «недели жизни».

## Как участвует AI (пайплайн Trigger → Input → Agent → Output)

- **Trigger** — планировщик (раз в неделю).
- **Input** — возраст ребёнка (номер недели), посчитанный из даты.
- **Agent** — RAG по корпусу гайдлайнов (поиск + реранкер + порог отказа) и языковая модель,
  которая отвечает по каждой рубрике строго из найденных источников, с проверкой цитат.
- **Output** — готовая заметка: на диск и в Telegram.

Ограничители: ответы только из источников (иначе честный отказ), запрет на дозировки и
диагнозы, явная маркировка «сгенерировано ИИ» и дисклеймер, что это не заменяет врача.

## Запуск

```
pip install -r requirements.txt          # или переиспользовать общий venv курса
cp .env.example .env                      # вписать ключи и дату (в git не идёт)
python run.py --now                       # собрать и отправить один раз
python run.py --serve                     # планировщик: раз в неделю
```

Или двойной клик по `Дайджест-бот.command` → бот в Telegram (`/start`, `/digest`).
