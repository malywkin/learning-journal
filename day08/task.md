# День 8. Работа с токенами

Добавьте в код агента подсчёт токенов:
- для текущего запроса
- для всей истории диалога
- для ответа модели

Сравните:
- короткий диалог
- длинный диалог
- диалог, который превышает лимит модели

Покажите:
- как растёт стоимость/токены по мере диалога
- что ломается при переполнении

**Результат:** код, который считает токены и показывает, как они влияют на поведение агента.

**Формат:** видео + код.

---

## Уточнение преподавателя (из чата)

- «Превышает лимит модели» — речь про **лимит контекстного окна**.
- Про рост стоимости: НЕ нужно реально доводить платную модель до переполнения и
  показывать списания. Достаточно диалога вменяемой длины, чтобы показать **динамику
  роста цены**.
- Главный смысл задания: понять, **как меняется поведение модели, когда старая часть
  контекста начинает «отъезжать»** из окна. (Преподаватель связал это с источником
  галлюцинаций — у нас это проверено и уточнено: потеря контекста меняет поведение,
  но «99% галлюцинаций» — гипербола; см. решение.)
