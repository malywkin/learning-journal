# День 30. Локальная LLM как приватный сервис

🔥 Разверните локальную LLM как сервис:

- 👉 на VPS или домашнем сервере
- 👉 с HTTP API
- 👉 с возможностью чата

Проверьте:

- 👉 доступ к модели по сети
- 👉 стабильность при нескольких запросах
- 👉 базовые ограничения (rate limit / max context)

**Результат:** Приватный AI-сервис на базе локальной LLM

**Формат:** Видео + Код

---

## Как решаем (наш выбор)

- **Домашний сервер, не VPS.** Правило Life OS: данные не покидают машину. Модель
  крутится на Mac, доступ только по домашней Wi-Fi (LAN), наружу в интернет НЕ торчит.
- **Ничего не ставим заново.** С Дней 27–29 уже стоит LM Studio с `qwen3.5-9b-mlx`
  на `localhost:1234` (OpenAI-совместимый HTTP API). Это и есть «локальная LLM с HTTP API».
- **Перед LM Studio — тонкий прокси** (`task30.py`, FastAPI). Наружу на Wi-Fi торчит
  ТОЛЬКО прокси; сам LM Studio остаётся на `localhost` и снаружи недоступен. Прокси даёт
  то, чего у голого демона нет: пароль на входе, ограничитель по токенам, обрезку контекста,
  очередь и веб-чат. Это «взрослый» reverse-proxy паттерн (не выставлять голый демон в сеть).

## Что прокси закрывает по заданию

| Пункт | Реализация |
|---|---|
| доступ по сети   | прокси слушает `0.0.0.0:8000`, телефон в Wi-Fi заходит на `http://192.168.0.102:8000` |
| чат              | прокси отдаёт HTML-страницу чата (стрим ответа) |
| стабильность     | семафор пропускает к MLX по одному, остальные честно ждут в очереди — сервер жив |
| rate limit       | скользящее окно по ТОКЕНАМ (не по числу запросов), сверх бюджета — `429` |
| max context      | длинный вход не роняем молча, а сами режем до окна модели |
| приватность/auth | ключ `Authorization: Bearer` на входе; наружу торчит прокси, не модель |

## Почему очередь, а не параллель

Наша `qwen3.5-9b-mlx` крутится на движке **MLX**, который (по состоянию на 2026)
обрабатывает запросы по одному. Параллельная обработка (continuous batching,
`Max Concurrent Predictions`) в LM Studio есть только на движке **llama.cpp/GGUF**.
Поэтому «стабильность при нескольких запросах» показываем как ЧЕСТНУЮ очередь под
защитой ограничителя, а не как параллельную молотилку. Для приватного домашнего
сервиса это правдивее.

## Запуск

```
# LM Studio запущен, qwen3.5-9b-mlx загружена (как на Дне 29)
Tasks/day21/.venv/bin/python -m uvicorn task30:app --host 0.0.0.0 --port 8000
# с Mac:      http://localhost:8000
# с телефона: http://192.168.0.102:8000  (та же Wi-Fi), ключ из .env
```
